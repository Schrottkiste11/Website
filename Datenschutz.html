Die Nutzung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer verlässlichen Bereitstellung unserer Webadresse).

3. Spezifische Datenverarbeitungen der Funktionen

a) Laut.fm Einbindung (Radio-Stream & Song-Abfragen)

Auf unseren Seiten (u. a. im Web-Radio) wird der Audio-Stream und die API des Internetradio-Anbieters laut.fm (laut.ag, Seestraße 9, 78464 Konstanz) eingebunden.

Um den Audio-Stream abzuspielen und die aktuellen Song-Informationen abzurufen, stellt Ihr Browser eine direkte Verbindung zu den Servern von laut.fm her. Hierbei wird Ihre IP-Adresse an laut.fm übermittelt und in deren Server-Logs verarbeitet. Dies ist technisch notwendig, um die Audiodaten an Ihren Browser zu übertragen.

Die Nutzung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der Bereitstellung von Multimediainhalten).

b) GitHub REST API (Soundboard Audio-Dateien)

Unser Soundboard nutzt die öffentliche GitHub REST API, um Audiodateien (MP3, WAV, OGG) dynamisch aus unserem Repository abzurufen und aufzulisten.

Bei der Abfrage der Titelliste stellt Ihr Browser eine Verbindung zur Schnittstelle api.github.com her. Dabei werden Ihre IP-Adresse und Browserdaten an GitHub übertragen. Es werden hierbei keine personenbezogenen Nutzerprofile erstellt oder Cookies von uns gespeichert.

c) Lokale Speicherung im Browser (Local Storage)

Diese Website nutzt den sogenannten Local Storage (lokaler Speicher) Ihres Browsers. Es werden dabei keine Cookies an unseren Server gesendet und keine personenbezogenen Nachverfolgungen durchgeführt.

Folgende Daten werden lokal auf Ihrem Endgerät gespeichert, um die Funktionalität des Soundboards und des Radios zu gewährleisten:

  • Erstellte Playlists: Von Ihnen lokal zusammengestellte Audio-Wiedergabelisten.
  • Wiedergabe-Historie: Zuletzt abgespielte Sounds zur Anzeige im Player.
  • Audio-Einstellungen: Gewählte Lautstärke, Stummschaltungs-Status (Mute) und Repeat-/Shuffle-Einstellungen.

Diese Daten verbleiben ausschließlich auf Ihrem Gerät und werden nicht an uns oder Dritte übertragen. Sie können den lokalen Speicher jederzeit über die Einstellungen Ihres Browsers löschen.

d) YouTube Video-Einbindungen

Auf einigen Unterseiten können Videos der Plattform YouTube eingebunden sein. Betreiber der Seiten ist die Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland.

Wenn Sie eine Seite mit eingebettetem YouTube-Video besuchen, wird eine Verbindung zu den Servern von YouTube aufgebaut. Dabei wird dem YouTube-Server mitgeteilt, welche unserer Seiten Sie besucht haben. Wenn Sie in Ihrem YouTube-Account eingeloggt sind, ermöglichen Sie YouTube, Ihr Surfverhalten direkt Ihrem persönlichen Profil zuzuordnen.

Die Nutzung erfolgt im Interesse einer ansprechenden Darstellung unserer Online-Angebote (Art. 6 Abs. 1 lit. f DSGVO).

e) Google Translate (Sprachauswahl)

Auf unserer Website ist die Übersetzungsfunktion von Google Translate eingebunden (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland).

Wenn Sie die Sprachauswahl nutzen, wird eine Verbindung zu den Servern von Google hergestellt, um die Übersetzung bereitzustellen. Dabei wird Ihre IP-Adresse an Google übertragen.

Die Nutzung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO aus dem berechtigten Interesse, die Inhalte unserer Website mehrsprachig und barrierefrei zur Verfügung zu stellen.
